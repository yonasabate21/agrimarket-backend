# 🌾 AgriMarket - Backend API

AgriMarket is a full-stack digital platform connecting agricultural producers directly with buyers and communities. This repository contains the backend RESTful API built with **Node.js**, **Express.js**, and **MongoDB**.

---

## ✨ Features

- **Authentication & Authorization:** Secure user registration, login, and role-based access control using JWT (JSON Web Tokens).
- **Product Management:** CRUD operations for agricultural listings, categories, and inventory.
- **Community Q&A Engine:** Interactive forum endpoints allowing farmers and buyers to ask questions and share knowledge.
- **Error Handling & Middleware:** Global async error handling and custom request validation.

---

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (via Mongoose ORM)
- **Authentication:** JSON Web Token (JWT) & bcryptjs
- **Environment Management:** dotenv

---

## 🚀 Quick Start
